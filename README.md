# 炸金花 · 联机版

一个可以 **2–8 人实时联机** 的炸金花小游戏。核心游戏零 npm 依赖，只用 Node.js 原生模块写成；电脑、平板、手机浏览器都能玩。可以局域网直接连，也可以用一条 Cloudflare 免费临时隧道让异地朋友加入。

- 服务端：Node.js（`http` + SSE/轮询，核心无 npm 依赖）
- 前端：原生 HTML / CSS / JavaScript
- 数据：内存房间，不需要数据库
- 积分：每人 0 分起，可负分；每局自动结算净分，结束时给出最少转账组合
- 机器人：房主可以添加 AI 陪练，自己一个人也能试玩
- 远程：`start-remote.bat` 一键启动 Cloudflare 临时公网隧道

**手机 + 电脑**：电脑上创建房间，点「手机加入」把局域网地址复制到手机；手机连同一个 WiFi 打开，填昵称即可同桌。**异地朋友**：运行 `start-remote.bat`，点「远程联机」复制公网链接。

## 快速开始

### Windows 一键启动

双击 `start-game.bat`，或在终端运行：

```powershell
node server.js
```

如果系统里没有 Node.js，脚本会尝试使用本机 DeepSeek Harness 自带的 Node 运行时。

启动后终端会打印：

```text
本机：   http://127.0.0.1:8787
局域网： http://192.168.x.x:8787
```

- 自己玩：浏览器打开 `http://127.0.0.1:8787`
- 和朋友联机：让朋友连同一个 WiFi，打开终端里的 **局域网地址**
- 想换端口：`$env:PORT=9000; node server.js`（PowerShell）

> 第一次运行时 Windows 防火墙可能会弹窗，请允许 Node.js 访问 **专用网络**，否则同一 WiFi 下的朋友连不进来。

### 手机 + 电脑一起玩

1. 在电脑上启动服务，打开 `http://127.0.0.1:8787`，创建房间。
2. 点房间顶部的 **「手机加入」**，会显示当前可用的局域网地址（带 `?room=房间号`）。
3. 让手机连同一个 WiFi，复制地址到手机浏览器打开。
4. 手机上填昵称、点「加入房间」，就会进入电脑所在的房间。
5. 如果第一个地址打不开，弹窗里会列出其他网卡地址；仍不行就检查 Windows 防火墙是否允许 Node.js 访问专用网络。
6. 不想复制地址时，也可以让手机打开局域网地址，在大厅输入 6 位房间号加入。

> 电脑上点房间号复制邀请链接时，如果当前是 `127.0.0.1` 打开，会自动换成局域网地址，方便直接发到手机。

### 远程联机（不在同一个 WiFi）

不想折腾局域网、端口转发，直接双击：

```text
start-remote.bat
```

脚本会：

1. 检查/启动本机的游戏服务器；
2. 用 `tools/cloudflared.exe` 开启一条 Cloudflare 免费临时隧道；
3. 在窗口里打印 `https://xxxx.trycloudflare.com` 公网地址；
4. 把地址写入 `runtime/public-url.txt`，游戏里的「远程联机」面板会自动读取。

然后：

1. 在游戏里创建房间；
2. 点右上角 **「远程联机」**，复制带房间号的公网链接；
3. 发给任何网络下的朋友，对方浏览器打开、填昵称即可加入；
4. **这台电脑和隧道窗口要保持运行**；隧道重启后公网地址会变，重新复制即可。

> Cloudflare 免费 quick tunnel 没有 uptime 保证，适合朋友间临时开局。长期固定联机建议使用带自己域名的命名 Cloudflare Tunnel，或把 `node server.js` 部署到一台有公网 IP 的 VPS。`tools/cloudflared.exe` 来自 Cloudflare（Apache-2.0）。

### 不想用本地电脑当服务器？

如果校园网/本机上行是瓶颈，直接把服务端搬到云端，本地只保留浏览器：

- 免费方案：Render Web Service（`render.yaml` 已准备好）
- 稳定方案：自己的 VPS + systemd + Caddy HTTPS
- 容器方案：`Dockerfile` / `Procfile` / `fly.toml` 已准备好
- 上传包：`zhajinhua-cloud.zip`

完整步骤见 **[DEPLOY.md](DEPLOY.md)**。部署后游戏里的「远程联机」会自动使用云端域名，不再需要 `start-remote.bat`，也不占用校园网上行。

> 远程模式使用 1 秒短轮询同步（因为部分隧道会缓冲 SSE），建议把牌桌留在前台；浏览器切后台可能降频，导致同步延迟。

如果手机能打开页面但连接不稳定，或完全打不开，可以在 Windows 上以**管理员身份**执行一次防火墙放行（只需一次）：

```powershell
New-NetFirewallRule -DisplayName "Zha Jin Hua 8787" -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow -Profile Private
```

### 局域网 / 互联网联机

- **同一 WiFi / 同一路由器**：直接用局域网地址，最省事。
- **不在同一个网络**：
  - 在路由器上把端口 `8787` 转发到这台电脑，朋友访问你的公网 IP；
  - 或者用 Tailscale / ZeroTier 等虚拟局域网工具；
  - 或者用 Cloudflare Tunnel / ngrok 把 `http://127.0.0.1:8787` 暴露出去。
- 这是给朋友之间玩的休闲服务，没有账号系统，公网暴露时请自行注意访问控制。

## 玩法

### 牌型大小

从大到小：

1. **豹子**：三张同点数，如 AAA
2. **同花顺**：同花色的三张顺子，如 ♠9 ♠10 ♠J
3. **金花**：三张同花色，如 ♥A ♥J ♥7
4. **顺子**：三张连续点数，如 ♠9 ♥10 ♦J
5. **对子**：两张同点数，如 ♠A ♥A ♦K
6. **单张**：以上都不是

- `A23` 是最小的顺子 / 同花顺，`QKA` 最大。
- 同牌型逐张比点数；点数完全相同时比花色：**黑桃 > 红桃 > 梅花 > 方块**。
- 可选地方玩法：**235 吃豹子** —— 不同花的 2-3-5 可以击败豹子，但输给对子、顺子、金花等。创建房间时可勾选。

### 下注规则

- 开局每人先交 **底注**，然后发 3 张暗牌。
- **闷牌**：不看牌，跟注 / 加注按当前单注的 **1 倍** 投入。
- **看牌**：随时可以看，免费；但看牌后所有跟注 / 加注按当前单注的 **2 倍** 投入。
- **跟注**：投入当前单注，继续留在局中。
- **加注**：把当前单注提高（不超过单注封顶），后面的人要按新单注跟。
- **比牌**：看牌后选择一名对手，支付 **双倍跟注额**（看牌后就是单注的 4 倍）。输的人直接出局。
  - 比牌双方会看到彼此的三张牌，其他玩家只看到“谁赢了”。
  - 一手牌结束时所有人都会摊牌。
- **弃牌**：放弃本局，已经投入的分数不退回。
- 最后剩下的一人赢走全部底池。
- 每回合有倒计时，超时自动弃牌；一局超过 120 次行动会自动摊牌。
- **没有分数上限**：每人从 0 分开始，下注不检查余额，分数可以为负。

### 积分与结算

- 每人初始 **0 分**，下注只是“本局投入”，不会提前扣分。
- 每局结束时结算一次：**本局净分 = 赢得的底池 − 本局投入**，累加到总分。
- 总分可以为负；负分也能继续参加下一局。
- 点「结算算分」查看本场总账：正分玩家应收，负分玩家应付，系统会自动给出**最少转账组合**（例如 B 给 A 10 分）。
- 房主可以在结算面板点「清零新赛季」，所有人回到 0 分重新开始。
- 中途离开的玩家会被记入结算账本，标记为“已离开”；机器人陪练的分数不计入真人结算。

### 房间

- 最多 8 人，最少 2 人开局。
- 每局结束默认**停在结算画面**，房主看好分数后再开下一局；也可以在设置里打开“自动开始下一局”。
- 牌局中途加入的人会先旁观，下一局自动入座。
- 房主可以改底注、单注封顶、回合时限、235 规则、公开/私密、自动开始下一局，还可以添加/移除机器人，或请离挂机玩家。
- 房主离开后会自动把房主移交给下一位在线玩家。
- 断线重连时如果正好轮到你，回合倒计时会恢复成完整时间（每局最多补一次）。
- 积分、胜负、每局净分会记录在“排行”里。

## 界面操作

- **看牌**：翻牌后底部会显示牌型；看牌后注额翻倍。
- **跟注 / 加注 / 比牌 / 弃牌**：轮到你时在底部操作栏。
- **加注**：弹窗里拖滑块或点预设金额，确认后完成。
- **比牌**：选择一个对手，弹窗会显示双方牌型和胜负。
- **邀请**：点顶部的房间号可以复制邀请链接；朋友打开链接、填昵称即可加入。
- **结算**：点顶部「结算」、右侧「排行」里的「结算算分」，或每局结束操作栏里的「结算算分」，查看总账和建议转账。
- **离场提醒**：还有未结清分数时，离开房间会先提醒你截图或复制结算。
- **战况**：桌面右侧是实时战况和聊天；手机上点顶部 `☰` 打开抽屉。
- **音效**：顶部 `♪` 开关；第一次点击页面后才会初始化音频。

## 说明

- 房间数据保存在内存里，**重启服务端会清空所有房间**。
- 登录凭证是保存在浏览器 `localStorage` 的随机 token；清掉浏览器存储后需要重新加入。
- 房间号是 6 位随机码，房间默认不公开；勾选「公开房间」后才会出现在大厅列表。
- 积分是零和账本：每局所有人的净分相加为 0；中途有人离开时，离开者的分数会保留在结算账本里。
- 机器人陪练的分数不计入真人结算；如果桌上混有机器人，真人分数可能不平账，界面会提示差额。
- 远程联机使用 Cloudflare 免费 quick tunnel，地址每次重启会变，且没有 uptime 保证；长期使用请部署到自己的服务器或使用命名隧道。
- 服务端本身没有 npm 依赖，不需要 `npm install`；`tools/cloudflared.exe` 是 Cloudflare 官方 Tunnel 客户端（Apache-2.0）。
- 机器人只做简单启发式决策，目的是陪练/凑桌，不是高强度 AI。
- 这是朋友间娱乐项目，没有反作弊、账号、充值等系统；公网暴露时请只分享给朋友。
